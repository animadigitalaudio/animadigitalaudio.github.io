macOS installation

One Terminal command and you're in.

Easy Wizard is distributed outside the Mac App Store, so macOS Gatekeeper quarantines the download and may say the plug-in "is damaged" or "can't be verified". The files are fine — remove the quarantine flag once.

  1. Easiest: unzip the download and double-click Install Easy Wizard.command. If macOS blocks it, right-click → Open.
  2. Manual: copy the .vst3 files to /Library/Audio/Plug-Ins/VST3/ and the .component files to /Library/Audio/Plug-Ins/Components/.
  3. Open Terminal (Applications → Utilities) and run the command for each plug-in. Enter your Mac password when asked — it stays invisible while you type.
  4. Restart your DAW or rescan plug-ins.
General form 
sudo xattr -rd com.apple.quarantine /path/to/plugin.vst3
All four Easy Wizard plug-ins 
sudo xattr -rd com.apple.quarantine "/Library/Audio/Plug-Ins/VST3/Easy Wizard (Synth).vst3"
sudo xattr -rd com.apple.quarantine "/Library/Audio/Plug-Ins/VST3/Easy Wizard (Fx).vst3"
sudo xattr -rd com.apple.quarantine "/Library/Audio/Plug-Ins/Components/Easy Wizard (Synth).component"
sudo xattr -rd com.apple.quarantine "/Library/Audio/Plug-Ins/Components/Easy Wizard (Fx).component"
killall -9 AudioComponentRegistrar

Keep the quotes — the file names contain spaces and brackets.
